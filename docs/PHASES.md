# Delivery phases

1. Repository setup, Docker Compose, database models, authentication and roles.
2. Menu, daily logs, calendar, CSV import/export and synthetic demo data.
3. Dashboard, analytics, rule-based insights and alerts.
4. ML service, benchmarks, training, backtesting and model registry.
5. Tomorrow's Plan, manager overrides and accuracy tracking.
6. PDF reports, broader tests, security review, CI and deployment guide.

Work stops for review after each phase. Features in later phases are not implied to exist until delivered.
